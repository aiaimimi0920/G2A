# 伙伴记忆迁移：候选契约

状态：**候选草案，不是已发布的线协议 profile**。本目录为 G2A r34 §9.7 与 §18 提供一个范围明确的技术提案，不新增核心操作、不改变 SDK。中英文具有相同要求。跨服务身份映射、传输认证、权限规则注册表仍需评审；JSON 校验不能授予权限。

## 1. 范围与文件

`schema.json` 用 JSON Schema 2020-12 定义 Export、Selection、Receipt 三种文档，`build_schema.py` 可重建。`vectors.json` 是公开正反向向量，`check_vectors.py` 是设计验证器而非服务端，`build_vectors.py` 可重建样本。这些测试不证明独立服务商互通或完整 G2A 符合性。

导出覆盖**导出时仍保留的全部伙伴记忆**，包括对话、场景、摘要、偏好，而不只是服务商选择的摘要。`retained_record_count` 统计同一一致性 `snapshot_id` 下已包含及明确受限/不可用的记录。每条记录带不透明 `record_id` 和修订标识。服务商必须与真实存量核对，包括各游戏/周目存储和索引；验证器只能发现计数不一致，不能证明服务商没有隐瞒源库存。已删除原始记忆无需重建或恢复。

## 2. 记录与媒体

`included` 记录必须携带内容和元数据：类型、原始时间、游戏/周目/存档上下文（null 代表不适用或未知，不代表权限）、来源、玩家编辑标记、派生与关联、硬访问/保留约束，以及独立的软保密风格。标识符属于服务商命名空间，不能假定跨服务同名等于同一身份。`source_provider` 与 `subject_id` 确定源身份空间；`companion_id` 保留源伙伴身份，不是目标服务登录凭据。

硬约束和扩展必须保留。无法理解硬约束时，导入方必须报告未解决/拒绝，不能默默扩大访问。软保密风格不得升级为禁止导出的硬规则；玩家授权迁移私密风格记忆不等于授权向游戏公开。本候选的约束为描述字符串，**不是可执行策略语言**；冻结版仍需注册可互操作的策略语义。未知扩展必须保留，或者诚实说明不支持/转换情况。

受限或不可用记录必须有占位条目及原因说明。如源标识本身会泄漏受保护信息，使用限定范围的不透明库存标识和去敏原因，不得为解释限制而泄漏内容。存在限制时不能声称全部内容无限制导出成功。

二进制内容通过 `blob_ids` 引用，每个引用必须恰好有一个描述条目。已包含媒体使用相对路径 `blobs/<不透明名称>`、字节数和**解压后文件原始字节**的 SHA-256。外部 URL 不是媒体内容，不自动抓取，也不能证明导出完整。丢失/受限媒体必须明确声明。只导入文字但缺失音频应记为 `transformed`，而不是 `imported`；必须保持原媒体类型和来源上下文可识别。

导入压缩包前必须拒绝路径穿越、绝对路径、重复条目、符号链接逃逸、超限解压大小和不支持的编码；不得执行内容。限制必须明确，不能静默截断。本候选不定义分块/断点续传；使用这类传输必须重建并校验相同的完整导出及媒体字节后才能宣告成功。单个分块到达不等于可用记忆。

## 3. 选择、授权与完整性

玩家发起导出/迁移并明确选择目标及记录 ID。Selection 中 `export_sha256` 是**实际传输的 UTF-8 导出 JSON 原始字节**的 SHA-256，不是解析后重新序列化的结果。要求无 BOM 的 UTF-8、无重复 JSON 字段名以及有限 JSON 数值。重新生成导出会改变摘要，需要对应的新选择；不假定通用 JSON 规范化算法。导出内媒体摘要进一步绑定媒体原始字节。摘要证明完整性，不证明身份或同意。

源和目标必须独立认证玩家、验证身份映射和授权。`selection_id` 或 JSON 中的声明不能替代授权核验。更换服务商或开启会话不自动导入，不能猜测标识符选择他人的库存。本格式不含 token 或凭据。具体认证/传输不在本候选内，不能据此暴露无认证导入接口。

选择 ID 在目标服务已认证玩家空间内唯一。同一选择与摘要的重试返回一致记账，不得重复生成记忆；同一 ID 搭配不同内容/目标必须拒绝。应用更改前须重新检查授权及相关已完成编辑/删除；旧导出不能默默恢复删除内容或覆盖玩家编辑。不能安全解决的冲突报告未解决，不按最新时间戳静默覆盖。本草案不虚构全局删除注册表。

## 4. 诚实收据

Receipt 绑定选择、原始导出摘要、目标服务和玩家。每个已选择记录恰好一个结果；不得导入未选择记录。状态为 `imported`、`transformed`、`rejected` 或 `unresolved`。成功项必须列出目标记录 ID；转换项解释转换及保留/丢失的语义；拒绝/未解决项不带成功目标 ID。不支持的内容/约束必须明确记账。`imported` 表示保留必要元数据的可用记忆，而非仅收到上传文件。不能将部分成功描述为全部成功。

导入不扩大公开权限、不重建已删除原件、不迁移模型权重，也不保证相同个性/回忆。真实服务符合性测试还需检查实际存储与检索、玩家编辑/删除、索引行为、权限保留，不能仅凭收据证明。

## 5. 执行和证据边界

安装仓库已有依赖 `jsonschema` 后，在本目录执行：

```text
python build_schema.py
python build_vectors.py
python check_vectors.py
```

验证器使用紧凑 JSON 仅为构造确定性的测试原始字节，不是通用规范化规则。向量 `accept` 是结构/关系校验预期，不是用户同意证明。真实认证、源库存完整性、安全解压、删除执行和实际检索属于独立服务符合性测试，发布前仍须完成。

本候选时间格式为 ISO 日历日期与时间，必须带 Z 或数值时区偏移，不表示闰秒 60。验证器直接检查日历合法性，因为 JSON Schema 的可选格式依赖不保证已安装。
