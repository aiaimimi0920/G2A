当前里程碑：建立实验性 `0.1.0-dev` 数据定义、规范和不依赖 Mot 的参考运行时。该版本不是稳定协议，以下未完成项不因首批测试通过而关闭。

## 实施顺序

1. 定义会话/角色/能力/策略/来源模型与一条有验证的传输绑定。
2. 参考运行时、SDK、协议正反例和真实传输验证。
3. 客户端呈现恢复、发现与两条加入路径、云端对接。
4. 非 Python 实现、最小 Godot 示例、互操作和安全审查。
5. 构建、文档网站、草案发布与逐项完整性审计。

## 2026-10-07 跨语言与来源记忆检查点
