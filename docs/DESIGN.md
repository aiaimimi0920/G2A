# G2A：Game-to-Agent

G2A 是面向游戏与玩家伙伴的独立双向交互协议构思。本文保留已确认的产品设计方向；当前实验规范与参考实现见 [SPECIFICATION.md](SPECIFICATION.md)，完整未完成项见 [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md)。有实验实现不等于已发布正式规范。

## 已明确的方向

- 任意游戏和 Agent 均可实现，不依赖 Mot 账号、服务器、模型或记忆服务。
- 聚焦玩家的固定伙伴身份，不扩展为任意 NPC 的智能化或接管协议。
- 支持已运行的本地伙伴发现游戏并询问或自动加入，也支持游戏主动提供连接入口，连接云端或唤起本地应用。
- 游戏声明呈现要求；退出默认恢复加入前的呈现状态，不回滚共同经历。
- 形象选择优先级为用户强制选择、游戏替代形象、伙伴默认形象；不兼容时明确反馈，不静默替换。
- 游戏决定信息开放和可用行动。协议不要求全知视角，形象也不赋予额外行动权限。
- 游戏可以表达本次游玩的行为要求；用户可以覆盖对话与陪伴偏好，但不能突破游戏的数据与行动权限。
- 伙伴可以参与私聊及队伍公开交流，保持同一身份和记忆；知道某件事不等于应向所有参与者公开。
- 支持伙伴主动表达及请求行动，不限定为一问一答。
- 不统一 Agent 内部的模型、记忆存储、人格或规划实现。

## 尚未决定

最低接入标准、能力分级、传输方式、认证与发现、消息格式、资源格式、版本兼容、断线恢复、多连接协调及一致性验证均待后续设计。不得将示例或构思误当作已经冻结的协议契约。

本目录不承载 Mot 专属业务。未来如增加 SDK 和参考实现，应保持可以独立使用；目前不提前创建空框架或绑定依赖。G2A 也不是 Mot 内部全部通信的统一协议。

协议可以独立演进，但是否独立发布、如何治理以及采用何种许可，尚未另行确定；本轮未改变仓库现有许可。
